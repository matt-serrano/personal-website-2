# Personal Portfolio Website

A modern, clean & minimal, dark theme, interactive personal portfolio website built with vanilla HTML, CSS, and JavaScript.

## Features

- 🎨 **Modern Dark Theme** - Eye-friendly dark color scheme with accent colors
- 📱 **Fully Responsive** - Works seamlessly on desktop, tablet, and mobile devices
- ✨ **Interactive Elements** - Smooth animations, hover effects, and scroll-triggered reveals
- 🎯 **Single Page Design** - All content on one page with smooth scroll navigation
- 🚀 **Fast & Lightweight** - No frameworks, pure vanilla JavaScript for optimal performance
- 🎭 **Smooth Animations** - Engaging transitions and parallax effects

## Sections

1. **Hero** - Eye-catching introduction with call-to-action buttons
2. **About** - Personal introduction and background
3. **Skills** - Technical skills organized by category
4. **Projects** - Showcase of featured projects
5. **Contact** - Multiple ways to get in touch

## Usage

Simply open `index.html` in a web browser to view the website. No build process or dependencies required!

## Customization

To customize the website for your own use:

1. Edit `index.html` to update personal information, projects, and content
2. Modify `styles.css` to change colors, fonts, and styling (CSS variables at the top)
3. Adjust `script.js` for interactive behavior customization

## Color Scheme

The website uses a carefully selected dark theme palette:
- Primary Background: `#0a192f`
- Secondary Background: `#112240`
- Accent Color: `#64ffda` (Teal/Cyan)
- Text Primary: `#ccd6f6`
- Text Secondary: `#8892b0`
